# Typing Speed Analyzer ⌨️

A **React-based typing speed test** that measures your typing speed (WPM) and accuracy, and stores top scores in a leaderboard.

---

## Features

- **Random Quote Generator** – Get a new sentence to type every test  
- **Word-by-Word Accuracy** – Fair calculation even if you miss letters  
- **WPM (Words Per Minute)** calculation  
- **Timer & Result Buttons** – See your time taken, WPM, and accuracy  
- **Leaderboard** – Top 10 scores stored in localStorage  
- **Validation** – Only high accuracy scores (≥ 95%) get added  
- **Clean, Responsive UI** – Works perfectly on desktop

## Installation & Run Locally

1. **Clone the repo**

```bash
git clone https://github.com/Rajbongshi-dev7/typing-speed-analyzer.git
cd typing-speed-analyzer
2.Install dependencies
npm install
3.Run the app
npm run dev
#If using CRA
npm start
4.Open in browser
http://localhost:5173 (Vite) OR http://localhost:3000 (CRA)
```
###Usage

Click Start Test
Type the sentence shown in the box
Finish the sentence → Timer stops automatically
Accuracy ≥ 95% → Enter your name → Score saved in leaderboard
WPM, Accuracy, and Timer are displayed in buttons
